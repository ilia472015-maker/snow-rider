# Снежный гонщик 🏔️🛷

Мобильная игра на Python (Pygame), где нужно кататься по снегу, собирать монеты и покупать улучшения и новый транспорт.

## 🎮 Как играть
* Управление происходит касанием пальца (герой плавно летит за пальцем).
* Собирай монеты и избегай деревьев.
* Нажми на кнопку 🛒 в правом верхнем углу, чтобы открыть магазин.
* В магазине можно купить новый транспорт (сноуборд, снегоход и т.д.) и улучшения (скорость, магнит).

## 🚀 Как запустить
1. Установите библиотеку Pygame: `pip install pygame`
2. Запустите файл: `python snow.py`

## 📱 Запуск на телефоне
Игра адаптирована под сенсорные экраны. Отлично работает на Android в приложении **Pydroid 3** и на iOS в **Pythonista**.
